[1] 사이트 편집하는 법 — Pages CMS (Google Sites 처럼 폼에서 편집)
══════════════════════════════════════════════════════════
처음 한 번만:
 1) https://app.pagescms.org 접속 → "Sign in with GitHub" → GitHub 계정(icallingyou)으로 로그인
 2) 안내에 따라 Pages CMS GitHub App 을 설치하고, 저장소 목록에서 jiaekim-site 를 선택
    (저장소 선택 화면에서 "Only select repositories" → jiaekim-site 만 체크하면 됩니다)
 3) 저장소를 열면 왼쪽 메뉴에 아래 항목이 보입니다 (설정 파일 .pages.yml 이 이미 들어 있어 따로 만들 것 없음)

매번 편집할 때:
 - 왼쪽 메뉴에서 항목을 고르고 → 내용을 고치고 → 오른쪽 위 Save
 - Save 하면 GitHub 에 자동 저장(커밋)되고, 1~2분 뒤 jiaekim.com 에 반영됩니다. (새로고침해서 확인)
 - 사진은 '사진' 칸에서 바로 업로드합니다. images 폴더에 저장되며, 가로·세로 픽셀 크기는 자동으로 채워집니다(1~2분).
 - 한국어 칸과 영어 칸이 따로 있습니다. 영어 칸을 비워 두면 한국어가 그대로 보입니다.
 - 기울임(이탤릭)은 글자를 *별표*로 감싸면 됩니다. 예: *Quilt of Hopes* — Flushing Town Hall

메뉴 항목:
 - 작품            : 작품 목록. 한 작품 = 사진 + 제목(한/영) + 줄 번호 + 연도 + 재료·크기 + 크게 보기 설명.
                      '줄 번호'가 같은 작품끼리 한 줄에 나란히 걸립니다(한 줄에 2~3점이 보기 좋음).
                      목록의 순서(위→아래)가 사이트 순서입니다. 드래그로 순서를 바꿀 수 있습니다.
                      '재현 모사 작품'을 켜면 갤러리 맨 끝 재현 모사 묶음으로 갑니다.
 - 전시            : 전시 목록. '예정 표시'를 켜면 UPCOMING 배지, '사이트에 표시'를 끄면 숨겨집니다(초안 보관용).
                      ※ Door to Door(BHS 개인전 2027.8)는 숨김 상태로 들어 있습니다. 확정되면 날짜를 넣고 '사이트에 표시'를 켜세요.
 - 첫 화면 · 다음 전시 : 대표 사진, 이름 아래 문장, 버튼, '다음 전시' 라벨.
 - 소개 · 약력     : 소개 글(글 편집기), 낙관 옆 인용문, 약력 목록, 소개 아래 사진.
 - 민화 처방전     : 처방전 섹션 전체. '이 섹션 표시'를 끄면 메뉴에서도 사라집니다.
 - 스튜디오        : 커미션 · 프린트 · 뉴스레터 카드. 샵 주소/뉴스레터 폼 주소를 넣으면 버튼이 바뀝니다.
 - 작품 섹션 문구  : 작품 섹션 제목 아래 한 줄, 재현 모사 소제목.
 - 기본 정보       : 이름, 이메일, 인스타그램, 푸터 한 줄, 검색·공유용 제목, '한국어가 아닌 브라우저에는 영어로 열기'.

주의:
 - 사이트 주소(url) 칸은 바꾸지 마세요.
 - 사진 파일 이름은 영문·숫자로 (예 morando.jpg). 한글 이름도 되지만 링크가 길어집니다.
 - 저장 후 화면이 그대로면 1~2분 기다렸다가 새로고침(폰은 브라우저 캐시 때문에 조금 더 걸릴 수 있음).
 - GitHub 웹 편집기로 index.html 을 직접 고칠 일은 이제 없습니다. 디자인(색·글꼴·배치)을 바꾸고 싶으면 저(Claude)에게 말씀해 주세요.

[2] 파일 구성 (참고용)
══════════════════════════════════════════════════════════
 - index.html        : 디자인 틀(템플릿). 내용은 들어 있지 않습니다.
 - _data/*.yml       : 실제 내용. Pages CMS 가 이 파일들을 고칩니다. (works=작품, exhibitions=전시, hero=첫 화면, about=소개·약력,
                       prescription=처방전, studio=스튜디오, gallery=작품 섹션 문구, site=기본 정보)
 - images/           : 사진. images/press/ 는 그랜트·공모용 고해상도 워크샘플(주소: https://jiaekim.com/images/press/파일명)
 - .pages.yml        : Pages CMS 편집 메뉴 정의
 - .github/workflows/image-sizes.yml + scripts/fill_image_sizes.py : 사진 픽셀 크기를 자동으로 채우는 자동화
 - _config.yml       : GitHub Pages(Jekyll) 설정
 - CNAME             : 도메인(jiaekim.com)

페이지 순서: 첫 화면 → Ⅰ 작품 → Ⅱ 민화 처방전 → Ⅲ 소개·약력 → Ⅳ 전시 → Ⅴ 스튜디오 → 푸터(연락)
 - 섹션 번호(Ⅰ, Ⅱ …)와 작품 번호(01, 02 …)는 자동입니다.

[3] 언어
══════════════════════════════════════════════════════════
 - 기본은 한국어. 오른쪽 위 EN 버튼으로 전환되고, 방문자가 고른 언어는 그 브라우저에 기억됩니다.
 - '기본 정보'의 "한국어가 아닌 브라우저에는 영어로 열기"가 켜져 있으면(현재 켜짐) 심사위원·큐레이터 등에게는 영어로 열립니다.
 - 공유용 주소: https://jiaekim.com/?lang=en (영어로 열림) · https://jiaekim.com/?lang=kr (한국어로 열림)

[4] 호스팅 (처음 올릴 때 했던 것 · 참고용)
══════════════════════════════════════════════════════════
