김지애 작가 사이트 v5 — 사용 안내 (2026.10 업데이트)

[올리는 법 · GitHub Pages]
1) github.com 로그인 → New repository (예: jiaekim-site, Public) 생성
2) "uploading an existing file" 클릭 → 이 폴더 안의 내용물 전체(index.html, CNAME, images 폴더)를 드래그 → Commit
3) Settings → Pages → Branch: main /(root) 저장
4) 같은 화면 Custom domain에 jiaekim.com 입력 → 이후 Squarespace DNS에 A레코드 4개 + CNAME(www) 추가 (이전에 드린 표 그대로)
※ 다른 도메인을 쓰기로 했다면 CNAME 파일 내용만 그 주소로 바꾸세요.

[⚠️ GitHub 웹 편집기에서 index.html을 고칠 때]
- 저장(Commit) 전에 파일 맨 아래가 </html> 로 끝나는지 꼭 확인하세요.
  (2026년 8월 수정 때 파일 뒷부분이 통째로 잘려 처방전·스튜디오·푸터·언어 전환이 사라진 적이 있습니다.)
- 저장 후 jiaekim.com 을 열어 맨 아래 푸터(이메일·인스타그램)가 보이고, 오른쪽 위 EN 버튼이 동작하면 정상입니다.
- 큰 수정은 저(Claude)에게 맡기시는 편이 안전합니다.

[페이지 구성 · 순서]
히어로(대표작 + 이름 + 버튼 + '다음 전시' 라벨) → Ⅰ 작품 → Ⅱ 민화 처방전 → Ⅲ 소개·약력 → Ⅳ 전시 → Ⅴ 스튜디오(커미션 · 프린트 · 뉴스레터) → 푸터(연락)
- 섹션 번호(Ⅰ, Ⅱ …)는 자동으로 매겨집니다. 섹션을 추가·삭제해도 손볼 것이 없습니다.
- 작품 번호(01, 02 …)도 자동입니다.

[나중에 교체할 자리 — index.html 안에 ★ 또는 ✏️ 표시로 주석해 두었습니다]
- 다음 전시: 플러싱 타운홀(2027.1) 세부 일정이 확정되면 두 곳을 고치세요 — 히어로의 '다음 전시' 라벨, 전시 목록 맨 위 줄.
  전시가 끝나면 전시 목록에서 badge 줄(예정/UPCOMING)만 지우면 됩니다.
- 뉴스레터: 스티비/Beehiiv 가입 후 form action 주소 교체 (그 전까지는 메일 앱으로 연결됨)
- 샵: 검로드/코파이 링크 생기면 '준비 중' 표시를 링크 버튼으로 교체
- 연잎과 봉오리: 제작 연도를 아시면 작품 설명 줄에 넣어주세요 (주석으로 표시해 둠)

[그림 한 점 추가하는 법]
1) 사진을 images/ 폴더에 넣기 (긴 변 1600px 정도 권장)
2) 사진의 가로·세로 픽셀 크기를 확인 (파일 정보에서 보임)
3) index.html의 작품 섹션에서 <figure class="art"> 블록 하나를 통째로 복사해, 원하는 줄(<div class="hang">) 안에 붙이기
4) 파일명 · --w/--h 와 width/height(2번에서 확인한 픽셀) · 제목(한/영) · 연도 · 크기 · data-cap-kr/data-cap-en(크게 보기 설명)만 수정
   - 한 줄(.hang)에 건 그림들은 높이가 같아지고 폭은 비율대로 정해집니다. 한 줄에 2~3점이 보기 좋습니다.
   - 새 줄이 필요하면 <div class="hang"> … </div> 묶음을 통째로 복사하세요.
- 또는 저(Claude)에게 사진과 정보를 주시면 수정본을 만들어 드립니다.

[언어]
- 기본은 한국어, 오른쪽 위 EN 버튼으로 전환. 방문자가 고른 언어는 그 브라우저에 기억됩니다.
- 공유용 주소: https://jiaekim.com/?lang=en (영어로 열림) · https://jiaekim.com/?lang=kr (한국어로 열림)
  → 인스타그램 프로필에는 ?lang=kr, 영어권 기관·큐레이터에게는 ?lang=en 주소를 주시면 됩니다.
- 브라우저 언어가 한국어가 아닌 방문자에게 자동으로 영어를 보여주고 싶으면 index.html 맨 위 <script> 안의
  "// if(!l&&navigator.language…" 줄 앞의 // 를 지우세요.
